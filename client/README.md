# Blogscape Client

This folder contains the active Next.js app.

## Current structure

- `app/`: App Router pages and API routes
- `src/`: UI components, auth helpers, SEO helpers, and client-side utilities
- `public/`: static assets

## Run the app

```bash
npm run dev
```

Other useful scripts:

- `npm run build`
- `npm run start`
- `npm run lint`
